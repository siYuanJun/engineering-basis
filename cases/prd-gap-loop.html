CASE 04 / 05PRD-GAP-LOOP

需求核对，做的是不是写的那件事

prd-gap-loop 把 PRD 条目和现有实现逐条对成一张台账，每条给固定判定、给证据、给验收人。下面三个样例走同一套检查，可以直接跑出同样的结果。

公开切片 ｜ 零依赖 ｜ 样例输出为 2026-11-24 本地实跑

01它解决什么

PRD 和实现对不上是常态。真正缺的不是清单，是判定：这条需求到底做到没有、做到一半、还是压根没做，差在哪一行、证据是什么、谁验的。没有这几样，对账会变成“我觉得做了”。

  • 一条需求一个判定，不用“基本完成”这种说法
  • 证据要能复核；P0 条目要运行态证据，文档不算
  • 验收人不能是开发人，自己验自己等于没验
  • 冲突条目停在待决策，不靠开发自行拍板

02三个可复现的判定

样例 A · 六条需求全部有据PASS
python3 demos/prd-gap-loop/check_gap_ledger.py \ --required demos/prd-gap-loop/fixtures/ids-pass.txt \ --ledger demos/prd-gap-loop/fixtures/ledger-pass.md
[R1] PASS [R2] PASS [R3] PASS [R4] PASS 统计: 行=6, 一致=1, 部分=1, 缺失=1, 多做=1, 冲突=1, 不适用=1 对账: required=5, ledger=6, 漏项=0, 未声明多出=0 结果: PASS · exit 0

五条 PRD 条目全部落在台账里，多出的一条“多做”已声明。P0 用真跑证据，验收人独立复跑。

样例 B · 自己验收自己FAIL
python3 demos/prd-gap-loop/check_gap_ledger.py \ --required demos/prd-gap-loop/fixtures/ids-pass.txt \ --ledger demos/prd-gap-loop/fixtures/ledger-self-signed.md
[R3] FAIL - FR-01: verified_by 不得等于 owner 结果: FAIL · exit 1

台账写得很完整，但验收人和负责人是同一个人。这种“闭环”只是自己签的字，检查直接判失败。

样例 C · 冲突条目没有决策人FAIL
python3 demos/prd-gap-loop/check_gap_ledger.py \ --required demos/prd-gap-loop/fixtures/ids-pass.txt \ --ledger demos/prd-gap-loop/fixtures/ledger-unresolved-conflict.md
[R4] FAIL - AC-01: 冲突行 notes 必须写「决策人」 - AC-01: 冲突行 notes 必须写「待裁决」 结果: FAIL · exit 1

PRD 和实现冲突时，不能由开发选一个继续做。必须写明决策人和待裁决，否则这条会悄悄变成“按实现为准”。

03规则是脚本拦截

四条检查都是确定性比对，不依赖评审人记不记得：条目双向差集、证据类型、验收独立性、冲突是否停在待决策。任何一条不过，台账就不算完成。

检查拦什么
R1 条目对账PRD 有条目但台账漏行；台账多出行但没声明
R2 证据与必填判定值不在六态内；P0 用文档当证据；证据指向不到具体位置
R3 验收独立性已闭环行的验收人等于负责人
R4 待决策阻塞冲突行没写决策人、没标待裁决

04判据与边界

维度口径
判什么PRD 条目与现有实现，逐条一判
判定取值一致、部分、缺失、多做、冲突、不适用；未取证的记待验证
什么时候算完成证据可复核、验收人独立、冲突已写明决策人
什么时候停手缺 PRD 基线、缺项目 adapter、冲突未裁决
职责范围出差距台账与交接包；不写代码、不替产品决策、不出验收结论

执行方式：本地运行，Python 3 直接跑；台账为 Markdown 表格，条目清单为文本；退出码 0 = 通过，1 = 有违规，2 = 输入或解析错误。

05怎么复现

git clone --depth 1 https://github.com/siYuanJun/engineering-basis cd engineering-basis for f in ledger-pass ledger-self-signed ledger-unresolved-conflict; do python3 demos/prd-gap-loop/check_gap_ledger.py \ --required demos/prd-gap-loop/fixtures/ids-pass.txt \ --ledger demos/prd-gap-loop/fixtures/$f.md done

三份台账为构造输入，覆盖正例、自签、冲突未决策三种情况。

本页与 demos/prd-gap-loop 为公开切片；完整工程含 adapter 模板、台账字段定义与交接包，在私有仓。
